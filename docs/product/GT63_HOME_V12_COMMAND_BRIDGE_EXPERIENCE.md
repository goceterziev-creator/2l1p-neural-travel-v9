# GT63 HOME V12 - Command Bridge Experience

## Status

LOCKED

## Document Classification

Document type: Product / UX Identity Spec

Scope: Presentation and experience only

Architecture impact: NONE

## Mission

Do not redesign GT63 as another admin panel.

Do not build another CRM.

Do not build another dashboard.

Build the feeling of entering the command bridge of a premium operating system.

When the agent opens GT63, the first emotion should be:

```text
Calm. Direction. Confidence.
```

The operator should immediately understand:

```text
I know exactly what I need to do next.
```

## North Star

GT63 is not travel software.

GT63 is a Travel Proposal Operating System.

Everything must reinforce:

- direction;
- decision support;
- confidence;
- speed;
- calm.

## Visual References

Reference direction:

- Apple;
- Linear;
- Palantir;
- Stripe.

Forbidden direction:

- gaming;
- crypto;
- cyberpunk;
- Dribbble gimmicks;
- glassmorphism overload.

## Design Principles

- Massive whitespace.
- Few elements.
- Perfect typography.
- Large breathing space.
- Clear hierarchy.
- Nothing decorative without purpose.

If an element does not help the operator, remove it.

## HOME Experience

The operator lands on HOME.

No dashboard overload.

Opening copy:

```text
Good morning, Goce.

What shall we create today?
```

Three primary actions only:

- New Proposal;
- Continue Proposal;
- Agency Overview.

Everything else is secondary.

## Active Workspace Principle

Once a proposal is opened, everything revolves around one client.

Not around menus.

Not around modules.

Not around the database.

The client becomes the center.

Around the client:

- flights;
- hotels;
- transfers;
- experiences;
- pricing;
- proposal.

Everything should feel like one living workspace.

## Compass

The GT63 compass is not decoration.

It represents progress.

- North: Proposal created.
- East: Validation complete.
- South: PDF ready.
- West: Client delivery ready.

When all four are illuminated, the center displays:

```text
READY TO SEND
```

No fireworks.

No celebration.

Only confidence.

## Colors

- Deep Navy.
- Midnight.
- Graphite.
- Electric Cyan accents only.

Almost monochrome.

Luxury software.

## Animations

- Subtle.
- 200-300ms.
- Nothing bounces.
- Nothing spins.
- Nothing screams.
- Everything breathes.

## Typography

- Premium.
- Readable.
- Confident.

Use typography instead of borders.

Use spacing instead of boxes.

Use hierarchy instead of colors.

## UX Rule

Every click must reduce uncertainty.

Never increase it.

The operator should always know:

- Where am I?
- What happened?
- What is the next step?

## Final Goal

Do not optimize for beautiful UI.

Optimize for this reaction:

```text
The operator opens GT63,
works for four hours,
closes the laptop,
and realizes:

I never fought the software.
```

That is success.

## Architecture Boundaries

Respect all existing architecture.

LOCK means LOCK.

Do not touch:

- Engine;
- Core;
- Provider Layer;
- Knowledge Layer;
- Renderer contracts.

Only improve presentation and experience.

## GT63 Principle #01

```text
A team means:
We share one goal.
Everyone contributes with their strongest ability.
```

Build a product that reflects this philosophy.
