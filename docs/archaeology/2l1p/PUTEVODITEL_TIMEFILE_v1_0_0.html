📋 1. ОБЩА ИНФОРМАЦИЯ BASIC

Проект: ПЪТЕВОДИТЕЛ - AI спътник в пътуванията

Тип: Уеб базирана платформа за търсене и резервация на пътувания

Цел: Предоставяне на лесна за използване платформа за търсене на полети, хотели и пакети

Технологии: HTML5, CSS3, JavaScript (Vanilla)

API интеграция: Amadeus API (планирана)

Статус: 🟢 Функционален прототип
